# 大飞鱼 Dafeiyu

从 [Leeks](https://github.com/huage2580/leeks) 的行情和持仓收益功能迁移而来的 Python 控制台程序。

支持 A 股、港股、美股、基金和加密货币行情，以及手动配置成本价和持仓后的收益估算。默认每 10 秒获取一轮行情。在终端中使用 Rich.Live 原地更新同一块看板，普通输出窗口自动使用逐轮输出。

## 启动

安装 Python 3.10 或更新版本后，在本目录打开终端，首次安装显示依赖：

```powershell
python -m pip install -r requirements.txt
```

然后启动：

```powershell
.\run.bat
```

也可以直接运行：

```powershell
python main.py
```

只输出一轮：

```powershell
.\run.bat --once
```

输出两轮、每轮相隔 10 秒：

```powershell
.\run.bat --count 2
```

按 `Ctrl+C` 停止。程序顺序执行每轮刷新；若请求耗时超过刷新间隔，会跳过已错过的时间点，避免多个刷新任务叠加。

体验原地刷新的看板，请在 IDE 底部的 **Terminal** 或 Windows Terminal 中运行。默认在同一块屏幕区域更新行情和收益，获取新数据时保留上一轮内容，按 `Ctrl+C` 后恢复正常终端。

在 IDE 中也可以选择 `main.py` 作为运行文件。普通 Run 输出窗口可能不支持控制光标位置，程序会提示并改为逐轮输出。若 IDE 的运行配置支持终端模拟，也可启用后再运行。

`--once` 和 `--count 1` 始终保留一份静态结果。需要将每轮输出留作记录时使用 `--display log`。若终端支持原地刷新但未被自动识别，可使用 `--display live` 强制开启。

在 Windows 的原地刷新终端中，按 `D` 可以展开/收起技术分明细，不用重启或重新请求行情。标题显示快捷键及当前明细状态；网络请求执行中按键会在本轮返回后响应。普通输出窗口、其他平台或单轮运行可用 `--score-details` 直接展开：

```powershell
.\run.bat --score-details
.\run.bat --once --score-details
```

KDJ 阶段、MACD 形态或技术分变化时，对应单元格会反色加粗约 3 秒，代码同时高亮，随后恢复。首次加载和旧数据/失败行不当作新信号；重绘提示不增加网络请求。逐轮日志模式保留普通快照。

项目的 `pyproject.toml` 声明了 Rich 依赖，`requirements.txt` 提供直接安装方式。请在与 IDE 项目相同的 Python 解释器中安装依赖。

## 表格展示

顶部集中显示沪深成交额、较前交易日同期/全天增减金额、增减比例和快照时间，全表只显示一次。下方行情与持仓合并为一张表，每只标的占一行，列为：代码、名称、涨跌幅、最高、最低、现价/净值、成本价、持仓、收益率、收益、KDJ(日)、MACD(日)、技术分、指标日期、行情时间。未配置持仓的字段显示 `--`。正涨跌幅和正收益显示红色，负值显示绿色；表头和交替行使用底色区分。

名称只显示前两个字，例如“东山精密”显示“东山”；以“科创”开头时跳过“科创”，取第三、第四个字，例如“科创半导体设备ETF华泰柏瑞”显示“半导”，“科创芯片ETF富国”显示“芯片”。

建议拉宽终端窗口以显示完整表格。窗口较窄时，最高/最低价会移到下方，必要时行情时间、指标日期、成本和持仓字段也会移到下方，优先保留收益、指标与技术分。数字不截断，极窄窗口改为逐项展示。混合类别或外币标的会增加类别、币种列；失败或旧报价会增加状态列。

所有已有日线都未收盘时，标题统一显示“盘中预估”，表格不再逐格重复 `(预)`。盘中与收盘数据混合时，标题显示“部分盘中预估”，相应行仍保留 `(预)`。缓存旧数据继续逐行显示 `(旧)`，技术分不可用时显示“待更新”。

行情时间是数据源时间。各行日期一致时，表内只显示时分秒；日期不一致时各行保留完整日期。休市时不会把旧报价标记为本机当前时间。

## 日线 KDJ 和 MACD

“收益”后展示 `KDJ(日)`、`MACD(日)`、`技术分` 和 `指标日期`。目前为沪深京股票及场内 ETF 计算，其他类别的指标显示 `--`。日线使用前复权数据，优先请求腾讯，失败时使用东方财富备用源；无需额外安装指标库。

- KDJ 参数为 `(9,3,3)`，K、D 初始值为 50，`J = 3K - 2D`。显示“死叉 → 即将金叉 → 金叉 → 即将死叉 → 死叉”的阶段状态。“金叉”表示当前 `K > D`，“死叉”表示当前 `K < D`，会在该阶段持续显示，不只显示交叉发生当天。`K = D` 且没有方向时显示“重合”。
- MACD 参数为 `(12,26,9)`，EMA 用首个收盘价初始化，`DIF = EMA12 - EMA26`、`DEA = EMA(DIF,9)`、柱值为 `2 × (DIF - DEA)`。显示“绿柱 → 即将红柱 → 红柱 → 即将绿柱 → 绿柱”的阶段状态；已为正值表示红柱，已为负值表示绿柱，零值且没有方向时显示“零轴”。颜色不按当天股价涨跌决定。
- 每只标的的日线最多每 60 秒请求一次，行情仍按原配置刷新。每次都比较日线，不比较相邻两轮控制台刷新。日线少于 34 根时显示 `--` 和原因；较长历史可减小初始化差异。
- `指标日期` 是实际参与计算的最后一根日线日期。当天 15:00 前的日线标记 `(预)`，盘中信号可能改变；收盘后取数才作为收盘信号。更新失败时保留先前指标并标记 `(旧)`，不会影响报价和收益继续更新。

“即将”的默认规则是本项目自定义的预警启发式，尚未验证预测成功率：

1. KDJ 使用差值 `X = K - D`；MACD 使用柱值 `X = 2 × (DIF - DEA)`。
2. 最近三根日线的 X 需要连续两次向零轴靠近，并且尚未穿越零轴。
3. 按这两次变化的平均速度 `V = abs(X最新 - X前两根) / 2` 估算，剩余根数 `abs(X最新) / V ≤ 2` 才显示“即将”。KDJ 额外要求 `abs(K - D) ≤ 5`。
4. MACD 使用距离/速度的比值，不设固定柱值门槛，以适应不同价格尺度。已经穿越时直接显示“金叉/死叉”或“红柱/绿柱”；接近后重新远离时撤销预警。

预警统一显示黄色。参数位于 `dafeiyu/indicators.py` 的 `WARNING_HORIZON`（默认 2 根日线）和 `KDJ_WARNING_GAP`（默认 5）。日线根数表示交易日，不是未来 2 秒、2 分钟或必然发生的交叉；盘中 `(预)` 与“即将”含义不同，前者表示本根日线尚未收盘。指标恒定地停在零轴时不强行给出方向。

界面会将上述阶段展开为更具体的文字：KDJ 刚发生交叉时显示“刚金叉/刚死叉”，后续按交易日根数显示“金叉第 N 日/死叉第 N 日”，无法确认起点时显示“金叉阶段/死叉阶段”。交叉日期仅从已有的完整 9 根回看窗口之后开始记录。MACD 与前一根日线比较绝对柱长，显示“红柱放大/缩短/持平”“绿柱放大/缩短/持平”；由负转正或由正转负时显示“新转红柱/新转绿柱”。接近交叉时保留当前形态并附“即将红柱/即将绿柱”。这些文字用于解释形态，技术分直接按下方的数值规则计算。

金叉、死叉的标准定义是交叉事件，本表按用户需要将名称用于交叉后的阶段。可参考 [KDJ 公式和交叉定义](https://support.futunn.com/topic149)、[MACD 公式](https://www.tradingview.com/support/solutions/43000502344-moving-average-convergence-divergence-macd-indicator/)。这里尚未自动识别顶背离、底背离。不同软件的参数、复权、初始值和柱值倍数可能不同。

## 技术分（-10 到 +10）

MACD 后的“技术分”列显示一位小数，例如 `+6.8`、`-4.3`、`0.0`、`+10.0`。评分按指标距离与变化幅度连续加权，不再为“金叉/死叉”直接给固定分数。盘中状态优先集中显示在标题，相同指标数值在盘中和收盘时得分一致，不再统一封顶 +6。分数越高，表示按本项目规则组合越偏正；越低表示组合越偏弱，接近 0 表示中性或信号冲突。它不是上涨概率、收益率、基本面估值，也不直接对应下单仓位。权重与尺度是项目自定义规则，尚未回测验证有效性。

记 `clip(x)` 为将数值限制在 [-1, 1]，`pos(x)` 为限制在 [0, 1]。`B` 是最近最多 20 根 MACD 绝对柱值的均值，含当前日线；`H0/H1/H2` 分别为最新、前一根、前两根有符号柱值。按以下项目加减：

| 项目 | 加减分 |
| --- | --- |
| KDJ 交叉 | `S = clip((K-D)/10)`，贡献 `3×S`，范围 -3 到 +3；越接近交叉，贡献越接近 0 |
| KDJ 位置 | 低位支持 `L = pos((50-(K+D)/2)/30) × max(S,0)`；过热程度 `T = pos(max((K-70)/30,(D-70)/30,(J-80)/40))`；贡献 `2×(L-T)`，范围 -2 到 +2 |
| MACD 柱强 | `2×clip(H0/(2B))`，范围 -2 到 +2；使用自身柱长基线，避免直接比较不同价格标的的绝对柱长 |
| MACD 变化 | `Δ = (2×(H0-H1)+(H1-H2))/3`；贡献 `2×clip(Δ/B)`，范围 -2 到 +2；最近一次变化权重更高 |
| 零轴趋势 | `clip(((DIF+DEA)/2)/(2B))`，范围 -1 到 +1 |
| 柱长风险 | `-2×pos((abs(H0)/B-2)/2)`；绝对柱长超过 2 倍基线后逐渐扣分，达到 4 倍时扣满 2 分 |

K 仍低于 D 时，不因 KDJ 读数低就自动获得低位支持分。高位风险逐渐扣分，避免原来的分段判定把不同形态压成相同分数。“即将金叉/死叉”“即将红柱/绿柱”仍作为界面预警，文字切换不额外给予固定加分或封顶。这里的 MACD 柱值上升包含正柱变长和负柱缩短；下降包含正柱缩短和负柱变长。参见 [MACD 柱值说明](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/macd-histogram)。两个指标都来自价格，不是两份独立证据。

各分项先四舍五入到 0.1 分后合计，最终限制在 [-10.0, +10.0]。不再应用原来的 +2/+5/+6 正分上限。`B=0` 表示提供的柱长全部为零，此时柱强、变化和柱长风险为 0；DIF/DEA 均值按正、负、零给趋势 +1、-1、0，避免除零或人为设置随股价变化的最小值。日线数据按原有间隔更新；细化评分不会增加行情请求，也不保证每轮分数都变化。

正分显示红色，负分显示绿色，0 分灰色，绝对值达到 7 时加粗。`0.0` 是真实中性分，不代表没有数据；指标缺失/数值无效时显示 `--`，报价或指标过期/失败、日期不一致时显示“待更新”，不会用 0 分代替缺失值。仅当显示的一位小数发生变化时高亮技术分，舍入前的微小变化不会反复闪动。

实现、权重与尺度位于 `dafeiyu/assessment.py`。按 `D` 或使用 `--score-details` 查看明细。每个结果保留 `components` 和 `reason`，包括最终范围调整项；显示的分项合计等于最终分数，便于检查评分来源。

## 大A量能（沪深两市成交额）

表格上方统一展示“沪深成交额”，单位是人民币亿元，表示本交易日截至来源更新时间的累计成交额，不是成交股数，也不是预计全天成交额。该数据为全市场快照，与单只个股成交额无关，不额外纳入技术评分。

同时显示相对上一交易日的增减金额与比例，例如“较前交易日同期 缩量 320.50亿元 (-4.99%)”，并注明“截至 MM-DD HH:MM”。比例使用未舍入的差额除以上一交易日基准金额计算；基准为零时显示“幅度--”。

- 盘中比较最近完整分钟：当前交易日与上一交易日在同一分钟的沪深累计额相减。总成交额也使用这个对齐分钟，避免金额与增减变化取自不同时间。实时行情仍按原配置刷新，量能比较最多滞后约一到两分钟。
- 盘中使用腾讯五日分时的累计成交额，不将累计值再次求和。上一交易日从两市实际返回的交易日期中取得，周一自动取上周五，节假日不按日历简单减一天。两市上一交易日不一致、缺少对应分钟或分时延迟超过两分钟时，不生成增减数值。
- 收盘后改用东方财富指数日线成交额，比较本交易日与上一交易日全天金额，显示“全天增量/全天缩量”。日线金额与收盘分钟可能因盘后更新存在差别，全天比较统一使用日线口径。
- 分时/日线历史按对齐分钟缓存，全表共用；同一分钟内不为每次 10 秒刷新反复下载历史。历史请求失败后至少间隔 60 秒重试，或到下一个对齐分钟再请求。
- 对比数据不可用时保留实时成交额，并显示“前日同期对比 --”，不把缺失基准算成零。对比原因保存在市场数据的 `comparison_error`；正常的增量/缩量只是成交活跃度变化，不代表股价方向。

口径为行情源的上证指数 `sh000001` 成交额 + 深证综指 `sz399106` 成交额，以元相加后除以一亿。使用沪深综合指数行情汇总口径，覆盖其股票范围（含行情源所含 A/B 股），不含北交所；不会再加创业板、科创板造成重复。它不是逐股对全 A 市场重新求和。范围可参考 [上交所指数成交额](https://www.sse.com.cn/market/sseindex/overview/)、[深证综指资料](https://www.cnindex.com.cn/module/index-detail.html?act_menu=1&indexCode=399106)。

实时快照优先批量请求东方财富，失败时用新浪完整指数行情作为备用；每轮只发起一次全市场读取任务，并与个股请求并行。沪深数据必须齐全、日期一致，更新时间相差不超过两分钟，才生成合计。取两者中较早的时间作为快照时间，金额使用 Decimal 计算。能够生成同期比较时，使用对应完整分钟的成交额和时间；收盘后使用日线金额。

缺失时显示 `--`；请求失败时保留先前快照并标记 `(旧)`，失败原因只显示一次。“截至”时间始终带 `MM-DD` 日期，以便休市、开盘前识别前一交易日数据。市场请求失败不会阻止行情、收益或指标刷新。

## 自选和持仓

编辑 `config.json`。默认自选列表仅用于演示，没有配置任何真实持仓。`config.example.json` 展示了虚构成本和数量的写法，按实际情况填写后使用。

```json
{
  "interval_seconds": 10,
  "fund_interval_seconds": 60,
  "timeout_seconds": 6,
  "stock_source": "tencent",
  "proxy": null,
  "stocks": [
    "sh000001",
    {"code": "sh600519", "cost_price": "1500", "quantity": "100"},
    "hk00700",
    "usAAPL"
  ],
  "funds": [
    {"code": "110013", "cost_price": "5.5", "quantity": "1000"}
  ],
  "coins": [
    {"code": "BTC-USD", "cost_price": "70000", "quantity": "0.01"}
  ]
}
```

- A 股代码：`sh600519`、`sz000001`；港股：`hk00700`；美股：`usAAPL`。
- 基金使用六位代码，例如 `110013`。
- 加密货币使用雅虎代码，例如 `BTC-USD`、`DOGE-USD`。
- 不关注的类别填写空数组 `[]`。
- `cost_price` 为每股/每份/每币的成本价，`quantity` 为股数/份额/币数。支持小数。
- 成本价为零或负数时仍可计算收益金额，收益率显示 `--`，避免无意义的除法。
- 也兼容原项目的单项写法，例如 `"sh600519,1500,100"`。
- 修改配置后，停止并重新运行程序使其生效。

收益金额 =（当前价格或净值 − 成本价）× 数量。收益率 =（当前价格或净值 − 成本价）÷ 成本价 × 100%。金额使用 `Decimal` 计算。每只标的按其报价币种显示，不跨币种求和；不计手续费、分红、拆合股或汇率变化。

## 数据来源与刷新

| 类别 | 来源 | 刷新说明 |
| --- | --- | --- |
| 股票 | 腾讯，支持沪深、港股、美股 | 每轮请求；可改为新浪 A 股备用源 |
| 基金 | 天天基金移动接口 | 默认至少间隔 60 秒请求；界面每轮仍显示最新缓存 |
| 加密货币 | 雅虎财经 Chart 接口 | 每轮请求；部分网络环境需要代理 |

原 Leeks 的基金估值地址和雅虎旧报价接口已发生变化，Python 版本使用了实测可访问的新地址。基金有估值时标记 `基金/估值`，没有估值时展示已公布的单位净值并标记 `基金/净值`，同时保留净值日期。

行情时间来自数据源；本机的刷新时间单独显示。休市期间显示的是来源最新报价，不会假装报价发生了更新。加密货币时间尾部的 `Z` 表示 UTC。

单个代码或行情源失败时，其他数据继续刷新。首次取不到的数据显示 `--`；已有报价更新失败时，会保留旧报价并明确标记 `更新失败/旧数据`。基金请求间隔内正常显示缓存，不会重复请求接口。

需要代理时，将 `proxy` 改为例如 `"http://127.0.0.1:7890"`。不配置时使用 Python 的默认系统/环境代理设置。不会关闭 HTTPS 证书校验。

## 常用命令

```powershell
# 只看指定股票，清空基金和币种列表
.\run.bat --stocks sh000001 hk00700 usAAPL --funds --coins --once

# 指定持仓，兼容 Leeks 的代码,成本价,数量格式
.\run.bat --stocks "sz000001,10,100" --funds --coins --once

# 使用另一份配置，改为每 30 秒刷新
.\run.bat --config config.example.json --interval 30

# 强制使用原地刷新的终端看板
.\run.bat --display live

# 每轮追加输出，方便查看历史或重定向到文件
.\run.bat --display log

# 只看 A 股，使用新浪备用源
.\run.bat --stock-source sina --stocks sh000001 sz000001 --funds --coins --once

# 查看全部参数
.\run.bat --help
```

网络请求默认超时 6 秒，可在配置中设置 `timeout_seconds`，也可用 `--timeout 10` 覆盖。有限轮数运行在最后一轮全部取数失败时返回状态码 1；配置错误返回 2；至少一个标的成功时返回 0。

## 文件结构

```text
main.py                  启动入口
run.bat                  Windows 快捷启动
config.json              默认自选列表
config.example.json      持仓配置示例（虚构数据）
dafeiyu/config.py         配置校验
dafeiyu/providers.py      股票、基金、币种接口
dafeiyu/models.py         行情、日线、指标模型和收益计算
dafeiyu/indicators.py     KDJ、MACD 日线计算
dafeiyu/assessment.py     技术指标组合评分
dafeiyu/market.py         沪深两市成交额解析与时间校验
dafeiyu/engine.py         并发取数、缓存与错误隔离
dafeiyu/scheduler.py      无重叠的定时刷新
dafeiyu/render.py         控制台表格
dafeiyu/presentation.py   信号文字、交叉日龄和短时高亮追踪
dafeiyu/display.py        Rich.Live 原地刷新和终端恢复
requirements.txt         显示依赖
tests/                   自动化验证
```

此版本不包含原 IDEA 插件的窗口、弹出走势图和隐蔽模式。
